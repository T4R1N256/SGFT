{% comment %} components/add_tile.html — Tile punteado «Agregar …» (patrón «Tile punteado» de Figma, rev. 1.1) Parámetros: text texto de la acción, por ejemplo «Agregar platillo» (obligatorio) hx_get vista que devuelve el diálogo; hx_target dónde se inserta (por ejemplo, #dialog) requires_pin True: muestra «Requiere PIN de administrador» con candado (informativo; valida el servidor) compact True: tile horizontal de 60 de alto con círculo de 32 (Inventario); si no, vertical con círculo de 64 Qué acción existe lo decide el servidor: si no hay hx_get, no se incluye. Incluir siempre con «only». {% endcomment %}
